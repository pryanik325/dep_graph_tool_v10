# Инструмент визуализации графа зависимостей (Вариант 10)

## Общее описание
Консольное приложение (CLI) для анализа и визуализации графа зависимостей пакетов. 
Текущий этап (Этап 1): Минимальный прототип с конфигурацией.
Приложение читает настройки из INI-файла, валидирует их и выводит на экран.

## Настройки (config.ini)
Все параметры задаются в файле `config.ini` в секции `[Settings]`:
- `package_name` — имя анализируемого пакета.
- `repo_url` — URL-адрес реестра пакетов (API) или путь к тестовому файлу.
- `test_mode` — режим работы с тестовым репозиторием (true/false).
- `package_version` — версия пакета.
- `ascii_tree` — вывод зависимостей в формате ASCII-дерева (true/false).
- `max_depth` — максимальная глубина анализа зависимостей.
- `filter_substring` — подстрока для фильтрации пакетов.
